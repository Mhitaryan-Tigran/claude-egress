# Claude Egress

Персональный выходной IP для Claude. Claude Code, Desktop и сайты Claude в обычном
браузере идут через ваш собственный VPS и всегда видны с одного адреса. Остальной
трафик и ваш обычный VPN не затрагиваются.

## Что нужно

- macOS 13 или новее (Windows подготовлен, но ещё не прошёл пилот).
- Свой Ubuntu VPS с публичным IPv4, доступными SSH и TCP 443.
- Свой аккаунт Claude.

Сервер у каждого свой: в программе нет ни чужих адресов, ни паролей. При первом
запуске она предложит добавить ваш.

## Установка

1. Скачайте `claude-egress-<версия>.zip` из [релизов](../../releases/latest).
2. Распакуйте и перенесите папку куда удобно, например в «Программы».
3. Откройте `Claude Egress.app`.

macOS при первом открытии скажет, что разработчик не подтверждён: откройте
«Системные настройки» → «Конфиденциальность и безопасность» и нажмите
«Всё равно открыть». Это нужно один раз — последующие обновления программа
ставит сама.

## Первый запуск

Программа закроет открытые Claude Code и Desktop, затем задаст четыре вопроса:

1. **Очистить данные Claude?** — по умолчанию «Нет», можно смело пропустить.
2. **Сервер** — «Добавить сервер», затем «Настроить сервер через SSH» и данные
   вашего VPS. Пароль спросит сам OpenSSH, программа его не сохраняет.
3. **Папка проекта** — где будет открываться Claude Code.
4. **Разрешить системный PAC** — нужно для сайтов Claude в обычном браузере.
   macOS попросит пароль администратора в своём окне.

Дальше появится главный экран. Нажмите «Вход CLI», завершите вход в браузере,
который откроется сам, затем «Терминал».

## Главный экран

Слева ваш обычный IP, справа — IP через сервер. Кнопка «Проксирование браузера»
перебирает три режима:

| Режим | Что идёт через ваш сервер в браузере |
| --- | --- |
| **Только Claude** | Сайты Claude и Anthropic. Остальное — обычным маршрутом. |
| **Все сайты** | Весь браузерный трафик, кроме localhost и локальной сети. |
| **Выключено** | Ничего, прежние настройки браузеров возвращаются. |

Пока окно открыто — канал работает. Закроете окно — соединение остановится.

## Обновления

Версия показана в шапке. Программа сама проверяет новую при запуске и предлагает
обновиться. Архив проверяется по контрольной сумме до установки.

## Если что-то не так

Красная панель наверху — нажмите на неё, чтобы увидеть подробности. Логи лежат в
`~/.config/claude-egress/`. Сбросить настройки прокси: закройте окно и выполните
`~/.local/bin/claude-net uninstall`.

## Честно о границах

Это не системный kill switch: программы, которые игнорируют настройки прокси,
могут выйти в сеть напрямую. Постоянный IP не гарантирует доступность сервиса или
отсутствие ограничений аккаунта. Windows и развёртывание на новом сервере ещё
требуют пилота.
